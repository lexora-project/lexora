# Lexora

Lexora is an AI-assisted multilingual reading layer for the browser. It helps users understand multilingual web content through contextual selected-text translation, explanation, pronunciation, and privacy-aware AI routing — going beyond generic word-for-word translation to deliver reading comprehension support in context.

## Status

Lexora v0.18.4 is available publicly on the Chrome Web Store. See the [installation guide](https://lexora.sh/install) for the official listing. This repository is a **public project hub** — it does not contain the full extension source code.

## Core Capabilities

- **Contextual translation** — selected-text translation with surrounding reading context
- **Explanation & definition** — inline explanations adapted to reading level and context
- **Pronunciation support** — phonetic and audio pronunciation guidance for selected text
- **Privacy-aware AI routing** — routes requests to translation providers, cloud AI, user-configured OpenAI-compatible endpoints, local AI runtimes (e.g. Ollama), or public knowledge sources (e.g. Wikipedia/Wikidata) based on user configuration
- **Multilingual web support** — designed for readers navigating foreign-language web content
