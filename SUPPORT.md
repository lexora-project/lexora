# Support

For support, visit the canonical support page:

**[https://lexora.sh/support](https://lexora.sh/support)**

You can also reach the team directly at [lexora.dev@proton.me](mailto:lexora.dev@proton.me).

## Reporting a Bug

When reporting a bug, please include the following information to help us reproduce and resolve the issue:

- **Browser version** — e.g. Chrome 125.0.6422.141
- **Lexora version** — shown in the extension popup or chrome://extensions
- **Operating system** — e.g. Windows 11, macOS 14, Ubuntu 22.04
- **Language pair** — e.g. Japanese → English
- **Provider mode** — the translation/AI provider you have configured
- **Reproduction steps** — a clear step-by-step description of how to trigger the issue

The more detail you provide, the faster we can investigate.

## Feature Requests
